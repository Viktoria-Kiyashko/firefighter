# ПОЖАРНЫЙ — прототип интернет-магазина

## Запуск
Распакуйте архив, откройте папку в VS Code. Запустите index.html через Live Server или из терминала: `python -m http.server 8000`, затем http://localhost:8000. Не рекомендуется использовать file://: поведение localStorage различается между браузерами.

## Состав
11 HTML-страниц, 3 CSS-файла, JS-каталог и общая логика, 9 оптимизированных изображений WebP. Без npm и внешних зависимостей. Поиск, фильтры, сортировка, карточки, размеры, избранное, корзина, тестовые заказы. Данные корзины, избранного и номера/суммы тестовых заказов хранятся локально. Контактные данные и пароли не сохраняются и не отправляются. Цены и размеры условные. Логотип — приближённая SVG-версия; заменить утверждённым оригиналом перед выпуском. Фото — концепты, не фотографии фактического товара. Нет серверной авторизации, реальной оплаты, доставки и отправки сообщений.

## Перенос на OpenCart
Версия OpenCart пока не определена. После выбора версии перенести общие header/footer в соответствующие Twig-шаблоны темы; index → common/home, catalog → product/category и product/search, product → product/product, cart → checkout/cart, checkout → штатное оформление, account → account, информационные страницы → information. favorites → account/wishlist. Подключить CSS/изображения через тему. Заменить демонстрационный products.js на данные контроллеров OpenCart и карточки на Twig-циклы. Заменить localStorage корзины/избранного на штатные маршруты и AJAX выбранной версии, а формы — на штатные контроллеры с серверной валидацией. Не использовать демонстрационную логику заказов на рабочем сайте. Проверить доступность, фактические изображения, характеристики, права на символику, условия доставки/возврата и реквизиты продавца перед публикацией.
